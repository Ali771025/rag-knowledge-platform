# RAG Knowledge Platform

این مخزن نسخه عمومی و کم‌حجم سورس پروژه برای معرفی نمونه‌کار است.

A FastAPI and React source portfolio for document ingestion, retrieval, conversation and knowledge graph workflows.

## توانمندی‌های قابل بررسی

- Backend modules separate ingestion, retrieval, graph knowledge and conversation memory.
- Frontend organizes workspaces, features, state and reusable components.
- Provider, database and task integrations are visible as source-level extension points.

ساختار و مسیر شروع در [README انگلیسی](../README.md) و [معماری](ARCHITECTURE.md) توضیح داده شده است. نمودارها ساختار کد را نمایش می‌دهند و تصویر اجرای نرم‌افزار نیستند.

قراردادها، مستندات خصوصی، پایگاه داده واقعی، کلیدها، فایل‌های حجیم و تاریخچه قبلی در این نسخه قرار ندارند. برای اجرا باید تنظیمات و سرویس‌های مستقل خود را فراهم کنید. این نسخه تست یا بیلد نشده است و ادعای آمادگی عملیاتی ندارد.
